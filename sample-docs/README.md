# sample-docs

ไฟล์สำหรับทดลองระบบ

| ไฟล์ | คืออะไร |
|---|---|
| `sample-regulation-th.pdf` | ระเบียบมหาวิทยาลัย**สมมติ** 7 หน้า หน้าละ 1 หมวด จึงรู้แน่ว่าคำตอบอยู่หน้าไหน |
| `test-questions.md` | คำถาม 21 ข้อ พร้อมคำตอบและหน้าที่ถูก |
| `source-regulation-th.html` | ต้นฉบับของ PDF เปิดใน Chrome แล้วสั่งพิมพ์เป็น PDF ใหม่ได้ ถ้าอยากแก้เนื้อหา |

## วิธีใช้

1. อัปโหลด `sample-regulation-th.pdf` ที่ http://localhost:3001 ควรได้ 7 หน้า ประมาณ 11 chunk
2. ลองคำถามจาก `test-questions.md` ในช่องทดสอบค้นหา แล้วจดว่าอันดับ 1 มาจากหน้าที่ถูกไหม
3. ข้อที่หาไม่เจอคือโจทย์ของสัปดาห์ 3 (เช่น คำถามที่ใช้ภาษาพูดต่างจากในเอกสาร)

## หาไฟล์จริงเพิ่ม

ค้น Google ว่า `ข้อบังคับมหาวิทยาลัย ว่าด้วยการศึกษาระดับปริญญาตรี filetype:pdf` จะเจอไฟล์ของหลายมหาวิทยาลัย

ก่อนใช้ให้เช็กว่าเป็น PDF ข้อความ ไม่ใช่ภาพสแกน: เปิดไฟล์แล้วลองลากคลุมหรือกด Ctrl+F หาคำ ถ้าคลุมไม่ได้ แปลว่าเป็นภาพ ต้องใช้ OCR

ไฟล์เก่าๆ บางไฟล์ใช้ฟอนต์ไทยรุ่นเก่า ทำให้ข้อความที่ดึงออกมาเพี้ยน เช่น วรรณยุกต์หาย (`ขอบังคับ` แทน `ข้อบังคับ`) หรือ `ำ` แตกเป็น ` า` ไฟล์แบบนี้เหมาะใช้ทดสอบว่าระบบรับมือกับข้อความเพี้ยนได้ดีแค่ไหน
